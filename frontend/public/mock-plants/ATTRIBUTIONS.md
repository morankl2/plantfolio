# Mock plant image attributions

These images are used only in `MOCK_PERENUAL=true` (test mode) — local
stand-ins for real Perenual photos, so development/testing doesn't spend the
free-tier API quota. All are sourced from Wikipedia / Wikimedia Commons,
resized and re-compressed for web use (originals unmodified otherwise).
